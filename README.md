# Buổi 7: Kết nối ReactJS & Cấu hình CORS
**Sinh viên thực hiện:** Nguyễn Phi Hùng (2123110475)

## 🎯 Nội dung công việc hoàn thành:
- Tích hợp thành công thư viện Axios trên Frontend (ReactJS) để gọi dữ liệu từ Backend.
- Cấu hình chính sách bảo mật CORS (`AllowReactApp`) trong file `Program.cs` của ASP.NET Core để cấp phép cho cổng 3000 (React) lấy tài nguyên.
- Kiểm thử luồng thông tin: Frontend gọi thành công vào Backend và nhận tín hiệu mã 200 OK.

- # Buổi 8: Hoàn thiện UI/UX & Bóc tách dữ liệu ReactJS
**Sinh viên thực hiện:** Nguyễn Phi Hùng (2123110475)

## 🎯 Nội dung công việc hoàn thành:
- Phân tích và xử lý thành công lớp vỏ dữ liệu kép: Bóc tách lớp vỏ `.data` của thư viện Axios và lớp `$values` của cấu trúc tuần tự hóa từ ASP.NET Core.
- Triển khai thuật toán xử lý dữ liệu động trên Frontend để hiển thị danh sách Bài viết và Sản phẩm cùng hình ảnh trực quan.
- Xây dựng tính năng Bộ lọc thông minh không cần tải lại trang (Single Page Application): Ép kiểu dữ liệu an toàn để đối chiếu ID, cho phép khách hàng lọc nội dung theo danh mục.
