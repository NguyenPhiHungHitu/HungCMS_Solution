## 🛠️ HƯỚNG DẪN CÀI ĐẶT & CHẠY DỰ ÁN

**1. Chạy Backend (ASP.NET Core)**
* Mở dự án bằng Visual Studio.
* Mở file `appsettings.json`, điều chỉnh `DefaultConnection` cho khớp với SQL Server máy cá nhân.
* Mở *Package Manager Console*, chạy lệnh: `Update-Database`.
* Nhấn `Ctrl + Shift + B` để build, sau đó nhấn `F5` để chạy Kestrel Server.
* Swagger API Documentation: `https://localhost:7044/swagger`
* Trang Admin Panel: `https://localhost:7044/`

**2. Chạy Frontend (ReactJS)**
* Mở terminal tại thư mục chứa code React.
* Cài đặt thư viện: `npm install`
* Khởi động dự án: `npm start`
* Truy cập trang chủ tại: `http://localhost:3000`
