# Buổi 5: Upload File & Quản lý Đơn hàng/Khách hàng
**Sinh viên thực hiện:** Nguyễn Phi Hùng (2123110475)

## 🎯 Nội dung công việc hoàn thành:
- **Phân hệ Bài viết (Posts):** Áp dụng kiến trúc `ViewModel` để bảo mật form nhập liệu. Viết logic xử lý Upload hình ảnh vật lý lên server (sử dụng `IWebHostEnvironment` và sinh tên file động bằng `GUID`).
- **Phân hệ Khách hàng:** Hiển thị danh sách khách hàng, dùng `.Include()` để thống kê số lượng đơn hàng từng người đã đặt.
- **Phân hệ Đơn hàng:** Hiển thị chi tiết đơn, cho phép Admin cập nhật các trạng thái xử lý đơn hàng và điều hướng linh hoạt (RedirectToAction).
