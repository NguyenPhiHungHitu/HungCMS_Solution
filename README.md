# Buổi 1: Khởi tạo Kiến trúc & Entities
**Sinh viên thực hiện:** Nguyễn Phi Hùng (2123110475)

## 🎯 Nội dung công việc hoàn thành:
- Khởi tạo kiến trúc dự án ASP.NET Core chuẩn mực cho hệ thống CMS Hùng Mobile.
- Xây dựng thành công các lớp thực thể (Entities) cốt lõi của hệ thống: `Category`, `Post`, `Product`, `Customer`, `Order`, `OrderDetail`.
- Thiết lập chuẩn xác các mối quan hệ (1-N) giữa các bảng bằng Data Annotations và ForeignKey.
- Đảm bảo tính đóng gói và chuẩn bị sẵn sàng cho bước Mapping vào Cơ sở dữ liệu.
